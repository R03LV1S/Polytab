Anti-Collusion Escrow Protocol

2-of-3 Multi-Sig & 48-Hour Challenge Lock

To prevent self-dealing ("The Bleacher Cartel"), project creators cannot unilaterally withdraw funds to themselves:

  1. Proof Enclosure: Worker submits before/after geo-tagged photo, TikTok proof (#PolytabProof), or Git commit hash.
  2. 48-Hour RSS Broadcast: GitHub Actions publishes the proof in ./feed.xml under an <enclosure> tag, starting a 48-hour public dispute window.
  3. 2-of-3 Sign-Off: Funds release only when 2 of 3 keyholders (Project Champion, Task Worker, Community/Accessibility Arbiter) co-sign the cold-storage transaction.
Adversarial Red-Team Hardening

Zero-Trust Pipeline Invariants

  • • Shell Injection Isolation: Untrusted GitHub Issue payloads are passed strictly via env: variables, never interpolated into run: bash blocks.
  • • Replay & Receipt Verification: The Python RPC verifier checks receipt.status == 1, recipient match, minimum Wei threshold, and hash uniqueness in votes.json.
  • • Serialized FIFO Concurrency: Workflow uses concurrency: cancel-in-progress: false with git pull --rebase to prevent TOCTOU race conditions.
  • • DOM Sanitization: Zero innerHTML rendering of user strings; strict regex guards on all EVM addresses and hashes.
Futarchy & Adversarial Outcome Markets

Vote on Values, Forecast with Pennies

Futarchy policy markets let small-dollar donations reveal which verified intervention a community believes works better. Every stake is a direct donation: 100% goes to the escrow of the intervention the staker chose — no protocol slice, no shared pot, no redistribution between outcomes, and no payout to anyone. Correct forecasts earn non-monetary reputation (a public accuracy rate, win/loss record, and badges), never money. Markets launch at $0 funded with an unset forecast split; numbers appear only after verified on-chain stakes.

  1. Tier 1 — Deterministic: A GitHub Action cron-fetches public data feeds (legislative dockets, agency APIs, school-district reports), SHA-256-verifies the body, and auto-settles hard metrics after the resolution deadline.
  2. Tier 2 — Community Dispute Window: Ambiguous resolutions post as public GitHub Issues with attached evidence; any staker may challenge within the 48–72 hour window by posting a dispute bond.
  3. Tier 3 — 2-of-3 Multi-Sig: Final call by the Project Champion, Task Worker, and Community/Accessibility Arbiter council — Accessibility markets always include a directly impacted stakeholder (Nothing About Us Without Us).

SHELVED PENDING LEGAL REVIEW: Adversarial accountability markets (“The Civic Short”) on named officials, corporations, or investigations present event-contract/gambling-law exposure and defamation risk. Only futarchy markets between verified 501(c)(3) interventions ship until counsel clears the adversarial tier.

Historical & Academic Foundation (2600 BCE → Web3)

From Sumerian Clay Tablets (Di-til-la) to polytab.store

Polytab draws its name and civic structure from the earliest documented human assemblies: the Sumerian bicameral Ukkin and the Old Kingdom Egyptian Djatjat and Kenbet councils. When those ancient citizen juries settled a public works obligation or civic judgment, they inscribed the completed legal verdict onto an immutable clay tablet known as a Di-til-la ("completed case"). Polytab revives the Di-til-la ("Poly-Tablet") for the global digital commons—combining EVM micro-ledgers with open RSS syndication so any community on Earth can coordinate and fund public goods at zero infrastructure cost.
